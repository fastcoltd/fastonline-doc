Tip 顶部提示

默认固定在页面顶部并在 4 秒后消失，也支持关闭按钮、描述文案和操作按钮。

四种状态与内容组合

FastFeedback.tip.success('操作成功');

FastFeedback.tip.warning({
    title: '请检查填写内容',
    description: '部分字段尚未填写完整。',
    actionText: '查看',
    duration: 4000,
    onAction: function (tip) {
        tip.close();
    }
});

Alert 确认框

弹框居中显示并锁定背景页面；点击遮罩和按 Esc 均不会关闭，只能使用弹框按钮。

FastFeedback.alert.confirm({
    type: 'warning',
    title: '确认删除？',
    message: '删除后无法恢复，请确认是否继续。',
    cancelText: '取消',
    confirmText: '确认删除',
    onCancel: function () {},
    onConfirm: function () {}
});

跨项目使用

复制组件的 CSS 和 JavaScript 文件，再按下面顺序引入即可。组件会在首次调用时自动创建 DOM。

<link rel="stylesheet" href="css/feedback-components.css" />
<script src="js/feedback-components.js"></script>
  • Tip 类型：success、info、warning、error。
  • duration 默认 4000；设置为 0 时不会自动消失。
  • Alert 的 onConfirm 可以返回 Promise；处理期间按钮会自动进入禁用状态。
  • onConfirm 返回 false 或 Promise 解析为 false 时，弹框保持显示。
  • 所有文案均通过 textContent 写入，不执行传入的 HTML。
